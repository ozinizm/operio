# Operio Render Free Demo Deployment Report

This report documents the configuration for deploying Operio to Render's Free Plan for a zero-cost live demo.

## 1. Why Render Free?
- **Zero Cost**: Render's free tier allows for a complete web service at no cost.
- **Ease of Use**: Single-service deployment with `render.yaml`.
- **FastAPI + React Synergy**: The backend serves the frontend static files, reducing complexity and service count.

## 2. Limitations of Free Plan
- **Spin-up Delay**: The service spins down after 15 minutes of inactivity. The first request may take up to 30-60 seconds.
- **SQLite Persistence**: Render's filesystem is ephemeral. **The database and uploaded files will be wiped on every deployment or restart.**
- **No Disk Storage**: Free plans do not support persistent disks.
- **Bandwidth**: Limited bandwidth, but sufficient for a staging demo.

## 3. Configuration Details
- **Single Service**: Backend (FastAPI) serves the API under `/api` and the React `dist/` for all other routes.
- **Environment**: 
  - `APP_ENV=production`
  - `DATABASE_URL=sqlite:///./operio_demo.db`
  - `FRONTEND_DIST_DIR=../dist`
- **Build Strategy**:
  1. Install backend dependencies.
  2. Install frontend dependencies and build (`npm run build`).
  3. Run `ensure_demo_seed.py` to initialize data if the DB is missing.

| SECRET_KEY | Generated by Render |
| CORS_ORIGINS | https://operio.fikircreative.com |

## 5. Domain Connection
To connect `operio.fikircreative.com`:
1. Go to Render Dashboard -> Settings -> Custom Domains.
2. Add `operio.fikircreative.com`.
3. Configure CNAME on Fikir Creative DNS to point to the Render service URL (`operio.onrender.com`).

## 6. Next Upgrade Path
1. **Render Paid Plan**: For persistent disk support ($7/mo).
2. **PostgreSQL**: Use Render Managed PostgreSQL or Supabase.
3. **S3 Storage**: Use AWS S3 or MinIO for permanent file storage.
4. **VPS**: Move to a VPS (Ubuntu) when traffic or persistence requirements grow.
